# 🌱 AgriAI

## 🚀 Smart Crop Disease Detection Platform

**AgriAI** is an AI-powered agriculture platform that helps farmers and agricultural professionals detect crop diseases using Deep Learning and Computer Vision.

Upload a crop leaf image, and AgriAI will:
- 🌿 Detect the disease
- ❤️ Calculate crop health score
- 📊 Display confidence score
- ⚠️ Identify disease severity
- 💊 Recommend treatment
- 🚜 Suggest farmer actions
- 🤖 Answer farming questions using AI
